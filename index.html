How these numbers are counted

  • The header row is not counted as a data row.
  • A cell counts as missing if it is empty or contains only whitespace.
  • Percentages are calculated against the number of data rows.
  • A duplicate is any repeated row after its first occurrence, compared on trimmed values and case-sensitively.

Privacy

This page has no backend. Your file is read with the browser's File API and analyzed in memory on your own machine. No file contents are sent anywhere, and the page works offline once loaded. You can confirm this in your browser's Network panel.
